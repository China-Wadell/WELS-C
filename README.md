# WELS-C

**Wadell Easy Language Series - Compiled**

一门为 Wadell ES 操作系统内核设计的、原生支持中文的通用编程语言，及其编译器、运行时、标准库、工具链、编辑器支持。

---

## 简介

WELS-C 是 Wadell ES 生态的编程语言层。它采用中英双关键字，语法贴近自然中文，同时保留底层系统编程所需的全部能力（指针、数组、结构体、内联汇编等）。

编译器 `wescc` 把 WELS-C 源码编译为 x86-64 汇编（Linux / Windows 双目标），最终由系统汇编器与链接器产出可执行文件。

## 目标

- **中英双语关键字**：`若 / if`、`循环 / for`、`函 / fn`，母语者无门槛
- **内核级能力**：指针、数组、结构体、内联汇编，能写操作系统
- **通用性**：不限于内核，任何用户态程序也能用
- **可自举**：未来用 WELS-C 重写 `wescc` 本身，脱离 GCC

## 编译

### 依赖

- GCC
- GNU Make

```
make              # 顶层，编译所有子项目
make test         # 跑测试

```

或单独编译编译器：

```

```

### 使用

```
wescc <file.wec> [-o out.s] [-target windows|linux] [-D NAME] [-I dir]
```

| 参数 | 说明 |
|---|---|
| `<file.wec>` | 源文件（必填） |
| `-o out.s` | 输出汇编文件（默认 `out.s`） |
| `-target linux` | 生成 Linux System V ABI 汇编（默认） |
| `-target windows` | 生成 Windows x64 ABI 汇编 |
| `-target wels` | 生成调用 WELS runtime 的汇编（不依赖 libc）|
| `-D NAME` | 定义宏 |
| `-I dir` | 加头文件搜索路径 |

### 完整流程（Linux）

```
cd compiler
./wescc tests/hello.wec -o out.s
gcc out.s -o hello
./hello
```

## 编译流程

```
.wec 源码
    ↓  预处理器（#<...>、#定宏、条件编译）
预处理后源码
    ↓  lexer.c    词法分析
token 流
    ↓  parser.c   语法分析
AST
    ↓  codegen.c  汇编生成
x86-64 汇编 (.s)
    ↓  gcc / as   汇编
目标文件 (.o)
    ↓  ld         链接
可执行文件 (.exe / ELF)
```

`wescc` 只负责前三个阶段，产出 `.s` 汇编。后续汇编与链接由系统工具链完成。
