# WELS-C

**Wadell Easy Language Series - Compiled**

一门为 Wadell ES 操作系统内核设计的、原生支持中文的通用编程语言，及其编译器 `wescc`。

---

## 简介

WELS-C 是 Wadell ES 生态的编程语言层。它采用中英双关键字，语法贴近自然中文，同时保留底层系统编程所需的全部能力（指针、数组、位运算、结构体等）。

编译器 `wescc` 把 WELS-C 源码编译为 x86-64 汇编（Linux / Windows 双目标），最终由系统汇编器与链接器产出可执行文件。

## 目标

- **中英双语关键字**：`若 / if`、`循环 / for`、`函 / fn`，母语者无门槛
- **内核级能力**：指针、数组、结构体、内联汇编，能写操作系统
- **通用性**：不限于内核，任何用户态程序也能用
- **可自举**：未来用 WELS-C 重写 `wescc` 本身，脱离 GCC

## 编译

### 依赖

- GCC
- GNU Make

### Linux

```bash
make clean && make
./wescc tests/bit.wec -o out.s
gcc out.s -o test && ./test
```

### Windows（MinGW / MSYS2）

```bash
make clean && make
./wescc tests/bit.wec -o out.s -target windows
gcc out.s -o test.exe
./test.exe
```

### 用法

```
wescc <file.wec> [-o out.s] [-target windows|linux]
```

| 参数 | 说明 |
|---|---|
| `<file.wec>` | 源文件（必填） |
| `-o out.s` | 输出汇编文件（默认 `out.s`） |
| `-target linux` | 生成 Linux System V ABI 汇编（默认） |
| `-target windows` | 生成 Windows x64 ABI 汇编 |

## 代码示例

```WELS-C
函 主 () -> 整数 {
    a 为 整数 10;
    b 为 整数 20;
    若 a < b {
        打印("a 比 b 小"\n);
    } 否则 {
        打印("a 比 b 大"\n);
    }
    返 0;
}
```

```WELS-C
函 主 () -> 整数 {
    i 为 整数 0;
    循环 i = 0; i < 3; i = i + 1 {
        打印("循环一次"\n);
    }
    返 0;
}
```

```WELS-C
函 主 () -> 整数 {
    a 为 整数 12;
    b 为 整数 10;
    c 为 整数 a & b;
    d 为 整数 a | b;
    e 为 整数 a ^ b;
    f 为 整数 1 << 4;
    g 为 整数 32 >> 2;
    若 c == 8 && d == 14 && e == 6 && f == 16 && g == 8 {
        打印("位运算通过"\n);
    } 否则 {
        打印("位运算失败"\n);
    }
    返 0;
}
```

## 编译流程

```
.wec 源码
    ↓  lexer.c    词法分析
token 流
    ↓  parser.c   语法分析
AST
    ↓  codegen.c  汇编生成
x86-64 汇编 (.s)
    ↓  gcc / as   汇编
目标文件 (.o)
    ↓  ld         链接
可执行文件 (.exe / ELF)
```

**注意**：`wescc` 只负责前三个阶段，产出 `.s` 汇编文件。后续汇编与链接由系统工具链（GCC / MinGW）完成。

## 与 C 的差异

| 项 | C | WELS-C |
|---|---|---|
| 声明 | `int a = 5;` | `a 为 整数 5;` |
| 类型位置 | 前 | 后（修饰符跟类型） |
| 不等于 | `!=` | `\=` |
| 幂 | 无 | `**` |
| 结构字段 | `;` 分隔 | 换行分隔 |
| 块 | 只有 `{}` | `{}` 或 `开始/结束` |
| 头文件 | `#include` | `#<file.weh>` |
| 模块 | 无 | `#导入<>` + `调用` |
| 注释 | `//` `/* */` | `_注释_` `_/ /_` |
| 字符串转义 | 字符串内 | `\n` 在字符串外 |
| 容器 | 无 | 有 |
| 区间 | 无 | 有 |
| 常量修改 | 不可改 | 可改（特殊语法） |
| 前置声明 | 需要 | 不需要 |

完整规范见 [WL-C26.md](WL-C26.md)。
